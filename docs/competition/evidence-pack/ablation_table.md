# 消融实验（三组对照）

| 实验组 | 最终 ASR | 攻击面覆盖 | 结论 |
|---|---|---|---|
| 完整系统(攻击进化+防御加固) | 0% | 7/7 | ASR 收敛到低位,加固覆盖被攻破类别。 |
| 去掉 Defense Agent | 30% | 7/7 | 无加固,ASR 始终高位 → 证明防御不可或缺。 |
| 去掉 Attack reflection | 6% | 2/7 | 攻击不进化,攻击面覆盖停滞 → 证明反思不可或缺。 |

> 完整系统 ASR 收敛到低位；去掉 Defense 则 ASR 高位不降；去掉 Attack reflection 则覆盖停滞——证明每个智能体都不可或缺。
