# AdvLoop 8 分钟答辩/讲解稿

## 开场：40 秒

各位老师好，我们的项目叫 AdvLoop，中文名“智驭”，面向的是“生成式大语言模型与智能体”方向。

一句话概括：我们不是做一个“用 Agent 完成购物任务”的系统，而是做一个“让 Attack、Evaluation、Defense 三类 Agent 自己解析任务、规划步骤、感知环境并自主决策”的系统。它解决的实际问题是 LLM / RAG 应用安全。

最终离线结果是：攻击成功率 ASR 从 44% 经过 7 轮加固下降到 0%；去掉 Defense Agent 后 ASR 仍保持 44%；去掉 Attack reflection 后攻击面覆盖只能停在 2/7，而完整系统可以覆盖 7/7。

## 问题背景：60 秒

现在的大模型智能体不只是聊天，它会检索知识库、调用工具、读写记忆，甚至执行订单、退款、改价这类业务动作。能力越强，任务也越复杂。

这类系统非常适合用智能体能力来处理：需要解析复杂任务目标，规划执行步骤，感知环境反馈，并根据结果自主决策。我们选择 LLM 安全作为应用场景，因为它天然需要攻击、评测和防御三种角色协同。

## 系统方案：90 秒

AdvLoop 由三个智能体和一个本地电商 RAG 环境组成。

第一个是 Attack Agent。它负责解析攻击目标，生成攻击计划，并记录攻击历史。如果攻击失败，它会做 reflection，沿策略阶梯升级，生成下一轮攻击变体。

第二个是 Evaluation Agent。它不是只看最后回答，而是读取完整轨迹，包括响应、工具调用、guard decision 和审计引用，然后输出 ASR、覆盖率、误伤率等指标。

第三个是 Defense Agent。它根据损伤报告自主选择加固动作，动作包括 prompt、rule、retrieval、rerank 等类型。它不是简单全拦，而是针对被攻破的威胁类别做精准加固。

靶场是本地电商 RAG Agent，覆盖搜索、导购、订单、支付模拟、退款、客服和商家运营。所有数据都是本地合成数据。

## 能力实现：150 秒

第一项能力是多智能体闭环。单条命令 `python run.py --closed-loop-demo` 可以离线串起攻击、环境、评测、防御和审计，生成 trace、report、guard decisions、audit refs 和 summary。

第二项能力是 Attack Agent 规划与反思。命令是 `python run.py --attack-campaign --offline`。Attack Agent 会在 7 类威胁上进行攻击规划，失败后反思并升级策略。离线结果显示，第一轮只覆盖 2 类威胁，加入 reflection 后可以覆盖 7/7。

第三项能力是 Defense Agent 自主决策。命令是 `python run.py --defense-regression --offline`。系统先跑基线攻击得到损伤报告，再让 Defense Agent 选择精准加固动作，然后重打同一攻击战役，并用良性请求测试误伤。结果是 ASR 从 44% 降到 0%，精准加固误伤率 0%。

第四项能力是决策证据包。命令是 `python run.py --evidence-pack --offline`。它生成 ASR 收敛曲线、加固前后损伤雷达图、消融实验和数据卡，把智能体决策效果转化成评委可以复现的证据。

## 实验结果：100 秒

我们重点看三个实验结论。

第一，系统能够收敛。初始 ASR 是 44%，经过 7 轮自主加固后降到 0%。

第二，Defense Agent 不可或缺。消融实验中，如果去掉 Defense Agent，只保留攻击和评测，最终 ASR 仍然保持 44%。

第三，Attack reflection 不可或缺。如果去掉攻击反思，攻击面覆盖停在 2/7；完整系统可以覆盖 7/7。

同时，精准加固误伤率是 0%，而一刀切防御误伤率是 100%。这说明 Defense Agent 的自主选型比简单阻断更有效。

## 创新总结：60 秒

我们认为项目创新主要有四点。

第一，把 LLM 安全从人工测试升级为多智能体自治闭环。

第二，把任务解析、步骤规划、环境感知、自主决策全部放进同一条可运行链路。

第三，用 ASR 作为统一指标，把智能体是否进化变成可观察的收敛曲线。

第四，所有核心结果支持离线确定性复现。无 API key 时，评委仍然可以用 `--offline` 跑出同样结论。

## 边界与收尾：20 秒

最后说明边界：项目只作用于本地合成电商靶场，不连接真实淘宝、真实支付、真实用户数据或外部攻击目标。
